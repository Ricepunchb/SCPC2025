# SCPC2025
2025 Samsung Collegiate Programming Challenge : AI 챌린지

# 대회 취지
**모델링 전략, 데이터 처리, 성능 최적화** 등 인공지능 개발 전반의 역량을 발휘하게 되며, 우수 참가자에게는 상금과 함께 *삼성전자 채용 우대* 혜택이 제공됩니다.

# 주제
사용자의 일상 사진을 이해하는 **멀티모달 AI 모델** 개발

참가자는 어떤 사용자의 스마트폰 갤러리에 저장된 다양한 일상 사진들에 대해 선다형 질문이 주어지면 정답을 선택하는 AI 모델을 개발
- Input: 사진, 선다형 질문
- Output: 정답 번호

# 평가식
$$\text{Weighted Accuracy} := \dfrac{\sum^N_{i=1}1[\hat{y}_i = y_i]\cdot w_i}{\sum^N_{i=1}w_i}$$
단, 평가 샘플 별 $w_i$는 비공개

## 1차 개발
- Public score : 제공된 축소 테스트 데이터 60개 샘플 100%
			🔹해당 기간 리더보드 순위/점수는 예선 평가에 반영되지 않습니다.
## 최종 개발 및 테스트 기간
- Public score : 최종 테스트 데이터 중 사전 샘플링된 50%
- Private score : 최종 테스트 데이터 100%

## 본선 평가
- 모델성능: (50점) Private 점수 반영 
- 데이터 활용: (10점) 데이터 수집, 전처리, 학습 과정별로 최적의 방법 적용
- 모델 설계: 문제 특성에 맞춘 효과적인 아키텍쳐 선택
- 성능 평가: 모델을 객관적 평가하고 모델 성능 점진적 개선
- 최적화: (10점) 원본 모델 성능을 최대한 유지하는 최적화 방법 적용 

# 제약조건
- 2023.12.31 이전에 공개된 오픈소스 모델 사용가능. 비상업적 라이센스
- API 모델 안됨
- 2025.6.10 이전에 공개된 외부 학습 데이터 사용가능. 비상업적 라이센스
    + 직접 촬영하거나 수기로 된 데이터 사용 불가
- 데이터는 출처, 사용방식, 데이터 파일 증빙 가능해야 하며 데이터 증강 과정이 다 코드로 제출되야 함
- 추론에 사용되는 파라미터 수가 **3B** 미만이여야 함
